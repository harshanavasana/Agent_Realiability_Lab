# Agent Reliability Lab (ARL) — Week 1: Execution Harness & Evaluation Fundamentals

Welcome to the **Agent Reliability Lab (ARL)** repository! This project is an engineering platform built to study, construct, test, evaluate, and continuously improve reliable AI agent systems.

This `week-1` branch contains the foundational **Deterministic Execution Harness** and **Initial Evaluation Engine** built completely from scratch in Python before introducing non-deterministic LLM components.

---

## 🎯 Week 1 Learning Objectives & Architecture

The core engineering principle of this lab is:
> **The harness controls how the agent operates, the evaluation system measures how well it operates, and the feedback loop uses evaluation results to improve the harness.**

### Highlights Implemented in Week 1:
1. **Tool Registry & Strict Pydantic Validation:**
   - Enforces schema types on all incoming tool arguments.
   - Utilizes Pydantic's `extra="forbid"` configuration to reject extra parameters generated by planners before function execution.
   - Centralized allowlist lookup (`get_tool()`) ensuring unauthorized tools cannot execute.

2. **Execution Controller & Budget Enforcement:**
   - `max_steps` limits to halt infinite execution loops.
   - `timeout_seconds` tracking to stop long-running operations safely.
   - Controlled execution loop capturing success, planner failure, tool failure, max steps exceeded, and timeout statuses.

3. **Structured Event Tracing & Observability:**
   - UUID-tagged `RunTrace` and `TraceEvent` objects tracking execution steps, planner choices, and tool invocation details.

4. **Deterministic Evaluation Engine & Auto-Reporting:**
   - Benchmark dataset loader (`evals/dataset.jsonl`).
   - Objective grading matrix evaluating task success and tool-use authorization independently (`evals/graders.py`).
   - Automated JSON evaluation reporting outputting results directly to `reports/`.
